# 新人 Onboarding 助手 PRD（NovaTech）

## 1. 背景与目标
帮助新人在入职 14 天内完成规范对齐与首个可交付抓手。

## 2. 目标客户
- 校招新人 PM
- 转岗产品同学

## 3. 功能需求
### P0
- 组织规范问答（基于知识库）
- 首周任务清单
- 历史踩坑提醒

### P1
- 导师匹配
- 学习路径推荐

## 4. 成功指标
- 14 日任务完成率 ≥ 80%
- 新人首次 PRD 评审一次通过率提升 20%

## 5. 风格要求
- 章节顺序固定：背景 → 客户 → 功能 → 指标 → 风险
- 详细度：适中偏详尽，关键决策必须给数据
- 术语优先使用：对齐、抓手、闭环、发版、客户
