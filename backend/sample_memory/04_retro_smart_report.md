# 复盘：智能周报助手下线（2025Q3）

## 项目背景
希望用 AI 自动汇总周报，降低填写成本。

## 结果
上线 6 周后回滚下线。

## 踩坑原因
1. 需求频次被高估：多数团队周报只是形式，不愿意改变习惯
2. 生成质量不稳定：缺少组织术语对齐，输出「正确的废话」
3. 未做小流量验证就全量发版，回滚成本高

## 经验教训
- 类似「自动生成文档」类需求，必须先验证真实使用频次与付费/采纳意愿
- 生成类功能必须注入组织术语与历史模板，否则信任度低
- 先闭环小流量实验指标，再扩大发版范围

## 建议
若再做同类需求，优先做「半自动草稿 + 一键采纳」，而不是全自动替换。
