# 待办清单 App PRD（NovaTech）

## 1. 背景与目标
目标：为忙碌职场人提供轻量任务管理抓手，完成「记录 → 提醒 → 完成」闭环。

## 2. 目标用户
- 学生
- 职场人士
- 家庭组织者

## 3. 功能需求
### P0
- 任务创建/编辑/删除（3 次点击内完成）
- 提醒（任务开始前 10 分钟）
- 标签分类

### P1
- 优先级排序
- 多端同步

## 4. 非功能需求
- 响应时间 < 200ms
- 支持 OAuth2.0

## 5. 里程碑
- Phase 1 MVP：8 周
- Phase 2 迭代：6 周

## 术语
- 发版：上线发布
- 客户：终端用户（内部不称“用户”）
